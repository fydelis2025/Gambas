## 📌 Sobre o Gambas
Gambas é um ambiente de desenvolvimento baseado em BASIC para Linux, 
com sintaxe similar ao Visual Basic. Foi a primeira base usada 
para idealizar os sistemas que hoje são construídos do zero.
